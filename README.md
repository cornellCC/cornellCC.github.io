# Cornell Consulting Consulting Club

Static website for Cornell Consulting Consulting Club. Each section is a separate HTML document; there is no client-side router or build step.

## Pages

- `index.html`: introduction and paths for club leaders and prospective members
- `about.html`: purpose and working principles
- `services.html`: practice directory and engagement model
- `organizational-strategy.html`, `recruitment.html`, `analyst-development.html`, `engagement-operations.html`: individual practices
- `team.html`: co-president profiles with expandable bios
- `join.html`: membership information and questions
- `contact.html`: local inquiry-draft download; nothing is submitted online

Open `index.html` directly, or serve this directory with a static HTTP server. GitHub Pages can serve the repository root on `main`. Shared styling and behavior live in `styles.css` and `app.js`.

## Design references

Reviewed October 9, 2026. These informed organization and presentation, not claims about this club or copied assets:

- [Cornell Consulting](https://www.cornellconsultingclub.org/): separate client, member, recruitment, and resource destinations; audience-specific homepage paths.
- [Cornell Consulting clients](https://www.cornellconsultingclub.org/clients): substantive engagement and project information.
- [Cornell Consult Your Community](https://www.cornellconsultyourcommunity.org/apply): dedicated applicant information and preparation guidance.
- [Bain services](https://www.bain.com/consulting-services/): services directory leading to individual practice pages.
- [Harvard Undergraduate CBE](https://www.hucbe.org/): distinct casework, team, contact, and application pages.

The design retains original architectural artwork and uses restrained typography, readable editorial columns, breadcrumbs, active navigation, and a practice sidebar. Team identities, recruitment dates, affiliations, and client achievements are not fabricated.
